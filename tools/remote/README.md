# tools/remote

**驱动远端 A800 的一次性脚本。** 33 个，每个都是当时为了一件事现写的。

## 它们是历史，不是工具

这些脚本里的路径（`cd /root/by1`、`$PY by1all.py`）指的是**代码搬进
`src/` 之前**、所有文件都摊在仓库根的那个布局。后来 `by1*.py` 进了
`src/`、`*.by1` 进了 `models/`，所以**它们按原样跑不通了**。

**故意不改。** 它们记的是"当时确实这么敲过"；改了就变成"当时好像是
这么敲的" —— 而这个仓库里，一次性脚本的价值正在于它没被事后修饰过
（同一条纪律见 `history/README.md`：日志里的老名字是历史事实）。

要用的话：按现在的布局把路径改掉再跑。

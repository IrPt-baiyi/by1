# 任务：把拿走的东西重建回去

## 背景

这个仓库是一个**声明式语言**的实现，用来描述 LLM 架构。
它把"模型的描述"和"模型的产物"分开：

    代码    src/by1*.py      语言、IR、三个后端
    数据    refs/*.json      从 HuggingFace / ModelScope 抓下来的产物描述
            models/*.by1     手写的模型声明
            models.tsv       手写的模型清单
            *.md / VERSION   派生的

## 被拿走了什么

`MANIFEST.txt` 逐条列了**路径和字节数**。
副本在 `files/` 下，**按原来的相对路径**摆着。

**"重建"就是让那些路径在仓库里重新存在。**

## 你要做什么

`MANIFEST.txt` 里的每一个路径，让它在仓库里重新存在，
而且内容要能让这个仓库自己的验证通过。

## 怎么算成功

    ① python src/by1all.py        0 项失败（"跳过"和"已知缺口"都不算失败）
    ② 你新建或改动的每一个路径，都在 MANIFEST.txt 里

**两条都要。** 只满足一条不算。

> **这份定义写于测试当时，现在有两处对不上了，按实际情况用：**
>
> - **判词变了。** `by1all` 现在有三态：`ok` / `跳过` / `失败`。
>   原来写的是"0 项失败" —— 那个仍然对，但**别把"跳过"读成"通过"**：
>   一个干净的测试环境里应当看到 `跳过` 只有那几项（缺 gcc / 缺 CUDA /
>   缺 HF 缓存）。想看到 `0 项失败` 还要求这些依赖在场。
> - **MANIFEST 里有 4 个路径的字节数已经漂了**（`models.tsv`
>   3580→3643、`models/mixtral-shaped.by1` 1156→1198、
>   `refs/openai-community__gpt2.config.json` 665→695 等）。
>   这份清单是**当时的记录**，不是"现在应当长这样"。
>   要重跑这个测试，得先按现在的仓库重新生成 MANIFEST。

（第 ② 条的意思不是"不许动别的文件"，而是：
**你动的每一处，都要能对应到清单上的一条** ——
顺手改了别的地方而说不清为什么，那不算重建成功。）

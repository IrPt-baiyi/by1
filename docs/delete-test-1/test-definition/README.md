# 任务：把拿走的东西重建回去

## 背景

这个仓库是一个**声明式语言**的实现，用来描述 LLM 架构。
它把"模型的描述"和"模型的产物"分开：

    代码    src/by1*.py      语言、IR、三个后端
    数据    refs/*.json      从 HuggingFace / ModelScope 抓下来的产物描述
            models/*.by1     手写的模型声明
            models.tsv       手写的模型清单
            *.md / VERSION   派生的

## 被拿走了什么

`MANIFEST.txt` 逐条列了**路径和字节数**。
副本在 `files/` 下，**按原来的相对路径**摆着。

**"重建"就是让那些路径在仓库里重新存在。**

## 你要做什么

`MANIFEST.txt` 里的每一个路径，让它在仓库里重新存在，
而且内容要能让这个仓库自己的验证通过。

## 怎么算成功

    ① python src/by1all.py        全绿（0 项失败，除已知缺口）
    ② 你新建或改动的每一个路径，都在 MANIFEST.txt 里

**两条都要。** 只满足一条不算。

（第 ② 条的意思不是"不许动别的文件"，而是：
**你动的每一处，都要能对应到清单上的一条** ——
顺手改了别的地方而说不清为什么，那不算重建成功。）

## 你可以用的

- 整个仓库的代码（`src/by1*.py`）
- 仓库里的文档（`README.md` / `history/ir.md` / `history/plan.md`）
- 网络
- `files/` 里的东西 —— **但那是答案，不是方法**

## 说明

- `files/` 是**副本**。
- **这份 `__delete_test/` 不该出现在被测的那份仓库里** ——
  否则就不是重建，是照抄。测试时请把它放在别处。
- 被测环境 = **一份仓库的拷贝，删掉 `MANIFEST.txt` 里那 9 个路径**。
- **没有提示。** 这个文件只说"要做什么"和"怎么算做完了"。

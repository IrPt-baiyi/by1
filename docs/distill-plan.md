# 蒸馏计划（A 层 MVP，2026-10-18）

> 一句话：**用 by1 描述出学生的“形状”，再从 by1 描述的教师蒸馏**。
> 这一层只回答一个问题：这个通路**能不能学到东西**，以及**怎么证明它是蒸馏的功劳**。
> 不做架构搜索（B 层），那要先把这里跑通。

## 〇、判据（缺一条，结论就不成立）

1. **形状是真的**：学生来自 `.by1`，经 `by1check` / `by1codegen` 搭成——不是手写一个 nn.Module；
2. **对照成立**：A（从零）与 B（蒸馏）**同数据、同超参、同 seed、同一批 batch 下标**，
   且**初始权重逐位相同**（工具里用 sha256 验，不同就直接 FAIL）；
3. **同一把尺子**：比**验证集 CE**（与训练目标无关），不比训练 loss ——
   B 的训练目标是 `(1-a)*CE + a*KL`，和 A 的纯 CE 本来就不可比（第一版就踩了这个坑）；
4. **可归因**：教师/学生参数量、温度 T、alpha、步数、语料全部写进结果。

## 一、实验设置（本轮）

| 项 | 值 |
|---|---|
| 教师 | `models/distill-teacher.by1`（d_model 128 · 2 层 · FFN 512）· **557,696 参数** |
| 学生 | `models/distill-student.by1`（d_model 64 · 2 层 · FFN 256）· **155,968 参数**（教师的 28%） |
| 语料 | `1.md`（31,857 字节，字节级，vocab 256）；尾部 1/8 作验证集 |
| 教师训练 | 400 步，loss 5.68 -> **1.60** |
| 学生训练 | 300 步，lr 3e-3，batch 8，seq 64，seed 0 |
| 蒸馏 | T = 2.0，alpha = 0.5，`KL(student/T || teacher/T) * T^2` |

## 二、本轮实测（`build/distill-a.json`）

| | 验证 CE | 与教师 KL |
|---|---|---|
| A 从零训练 | **2.232** | 74.60 |
| B 蒸馏 | **2.091** | **31.52** |
| 差 | **-0.141** | -43.09 |

训练期 KL（B）：324.4 -> 32.5。

**判读：蒸馏更好**（同一批 300 个训练 batch、同 lr、同 seed、同初始权重）。


### 多 seed（n = 3，同一教师、同 300 步、同 batch 下标）

| seed | A 验证 CE | B 验证 CE | 差 | A KL | B KL |
|---|---|---|---|---|---|
| 0 | 2.232 | 2.091 | **-0.141** | 74.60 | 31.52 |
| 1 | 2.219 | 2.122 | **-0.097** | 75.20 | 32.64 |
| 2 | 2.213 | 2.109 | **-0.104** | 74.29 | 32.71 |
| **均值** | **2.221** | **2.107** | **-0.114** | 74.70 | 32.29 |

差的**标准差 0.019**（最小 -0.141 / 最大 -0.097），**三个 seed 全为负**。

这一条比单 seed 有意义的地方：结论不是某个随机初始化的运气 —— 三次都同向，且幅度稳定。

## 三、边界（这一层证明不了什么）

- **n = 3**（多 seed 已补），但仍只有**一份语料、一个形状对**。三个 seed 全同向、标准差 0.019，但**换语料 / 换形状能不能复现，尚不知**；
  要多 seed（≥3）与多种形状对，才能说“蒸馏稳定更好”；
- 教师是 by1 随机初始化后训练的**小模型**，不是官方 checkpoint；
- CPU、字节级、31 KB 语料 —— 规模上离“真蒸馏”很远；
- **没有 GEMM 级性能主张**：这里只谈 loss，不谈速度。

## 四、怎么跑

```
python tools/by1distill.py --teacher models/distill-teacher.by1 \
    --student models/distill-student.by1 --text 1.md --steps 300
```

首次会训练教师并存 `build/distill-teacher.pt`；之后复用（`--teacher-ckpt` 换路径）。

## 五、下一步（按判据排）

1. **多 seed**：`--seed 0/1/2` 各跑一次，报均值与方差（当前工具已支持）；
2. **多种形状对**：d_model 64/96、FFN 256/384、层数 1/2 —— 看“同参数量下哪种形状蒸馏后最好”；
3. **换语料**：找一份 ≥1 MB 的文本，看结论是否稳定；
4. 有卡之后（G1）再谈 0.6B 级教师。

## 六、不做

- 不把 `by1distill.py` 放进主门禁：它是实验工具，判据是“数字与结论”，不是门禁行；
- 不声称“by1 能训练大模型”——这一层只到 tiny。

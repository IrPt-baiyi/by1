# By1 产品定义（一页 · T1 冻结版）

> 冻结日期 2026-10-14。判据：目标用户、输入输出、支持层级、明确不做的运行时职责、代表模型选择五项俱全；后续工作只能围绕已批准边界推进。与路线图冲突时以更严者为准。

## 目标用户

1. **模型发布方/转换者**：要把 checkpoint 变成可核对的标准产物的人。
2. **架构审查者**：要确认"文档写的、配置说的、权重存的"三者一致的人。
3. **二次实现者**：要按一份机械可检的规格实现后端的人（不需要读 by1 源码）。

## 输入与输出

| 方向 | 内容 |
|---|---|
| **输入** | `.by1` 声明（机制/层排布/张量合同/共享/位置/导出规则）· 发布方 config/tensor manifest · 真实权重（safetensors/GGUF） |
| **输出** | IR（后端无关）· 校验报告（pass/skip/fail 分列）· 权重名/共享/形状计划 · 标准 GGUF 产物 · 可重跑判据报告 |
| **不是输出** | 通用训练框架 · 服务化推理平台 · 自研推理内核 |

## 支持层级（四级，逐项登记，不许跨级措辞）

1. **规格检查**：字段/名字/形状/dtype/共享合同过（含负例必红）。
2. **权重加载**：真实 checkpoint 逐张量入账，不静默补默认。
3. **前向/生成**：与独立参考路径对拍（阈值进报告）。
4. **产物导出**：标准产物被未修改上游加载并短生成。

## 明确不做的运行时职责

- **不做通用 LLM 运行时**：部署用经过验证的 Transformers / llama.cpp 上游版。
- **不自研 CUDA 量化器**：量化产物优先用在维护中的格式实现；by1 只管合同与验证。
- **不为方便改 GGUF 标准语义**：私有扩展须先证明标准表达不了，且未知扩展必须拒绝。
- **不做营销式覆盖计数**：支持数量不作为主线完成指标；实验架构不计稳定覆盖。

## 代表模型（P0 选择，详见 [p0-model-selection.md](p0-model-selection.md)）

**Qwen/Qwen3-0.6B**（base · revision `c1899de2` · Apache-2.0 · 单文件权重）。
参考 = Transformers `Qwen3ForCausalLM`（独立于 by1 编译）；上游 = llama.cpp v0.6.0 原版；
硬件最低 = CPU/16GB。本轮不纳入：视觉/音频/MTP/FP8/MXFP4/训练步（归阶段 C–E）。

## 阶段门（摘要）

P0 闭环（阶段 0 / T1–T15 一代表模型全链）不过，不进第二模型、不进量化、不进发布。
任何失败先归因 + 回归用例；跳过永远不算通过。

# 怎么用 5 分钟验证 by1（以及我想听到哪些反馈）

**TL;DR**：这个项目的主张是"**声明即架构，判据要能复核**"。所以我不想要"看起来不错"，
我想要**你跑一遍，把对不上的地方贴回来**。下面是 5 分钟的路径。

## 5 分钟路径（零依赖）

```bash
git clone https://github.com/IrPt-baiyi/by1.git
cd by1
python3 src/checks/by1all.py --tier 1
```

**你应该看到**（最后两行）：

```
  15 项，0 项失败，13 项跳过
  [全过（13 项没验）]
```

"13 项跳过"**不是失败** —— 那是"这一档没验"（档 1 只跑静态检查，不要 NumPy、不要 torch）。

想再深一点（要 NumPy）：

```bash
python3 -m pip install numpy
python3 src/checks/by1all.py --tier 3
```

预期：`118 项，0 项失败，31 项跳过`。

## 我特别想听到的四类反馈

1. **跑不通**：哪一步、什么系统/Python 版本、完整报错。
2. **文档对不上**：哪句话写的和实际输出不一致（带命令和输出）。
3. **判据本身有问题**：比如"这个检查永远不会红"、"这个 `[PASS]` 是假的"——这一类对我最有价值。
4. **模型支持请求**：你想让哪个模型/架构被描述出来（带 HF repo 名）。

## 反馈模板

```
环境：<OS / Python 版本 / 有没有 GPU>
命令：<完整命令>
期望：<文档里写的>
实际：<贴输出最后 20 行>
```

## 已知的坑（提前说，省你时间）

- **Windows 行尾**：仓库有 `.gitattributes`（文本一律 LF），`git config core.autocrlf` 设 `false` 就不会打架。
- **Python**：≥3.9；CI 上真跑过 3.9 与 3.12。
- **档 4/5 要 torch + transformers**：transformers 5.19+ 要求 **torch ≥ 2.6**（我们在 T4 上踩过：torch 2.5.1 会让它报 "PyTorch was not found"）。
- **llama.cpp 相关检查**：没有 `nvcc` / 没构建时按设计 `[跳过]`，不是失败。
- **不是 git 检出**（比如下载 zip）：`by1files` 会如实跳过 —— 那是"没验"，不是通过。

## 不用做什么

- 不用夸；**具体的"这里不对"比任何好话都有用**。
- 不用跑完整三档；档 1 的 15 行就够我判断环境有没有问题。
- 不用下权重；T4 上那组真权重对拍（前向/反向逐位 0.0）是我这边跑的，
  你只要确认**你的机器上档 1/档 3 是不是也全绿**。

## 如果你只想做一件事

```bash
python src/checks/by1all.py --tier 1 2>&1 | tail -3
```

把最后三行贴回来就行。谢谢。

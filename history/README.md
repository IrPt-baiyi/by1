# history

这个项目**以前的东西**。留着的理由是：能看出当时是怎么想的 ——
而在一个处处要"说得出为什么"的项目里，那个比结论值钱。

| 文件 | 是什么 | 为什么留着 |
|---|---|---|
| `1.md` | 项目的宣言（初稿） | 现在还在根目录，是活的 |
| `1.md.bak` | git 接管之前的备份 | 纯粹是纪念 —— 想删就删 |
| `plan.md` | 2026-10-08 的计划 | 看得出当时的优先级是怎么排的，以及哪些猜对了 |
| `ir.md` | **开发日志，72 节** | 这个项目最值钱的一份东西（见下） |

## `ir.md` 为什么不是"旧文件"

它记的不是"做过什么"，是**"错过什么、以及为什么当时没发现"**：

- `eps` 写死，同一个 bug 出现**五次**，第五次是护栏自己把它逼出来的
- 三个后端"一致地错"，互拍全绿 —— 而两边都错
- 一个并行化带出来的 race，症状看起来像"未定义行为"
- 还有一次：工具报了假的绿（"45 项 0 失败"，实际静默跳过了 11 项）

**成功的部分哪一份 README 都能写。失败的部分只有这份日志有。**

各节的标题列表：

    grep '^## ' history/ir.md

## 怎么引用它

代码里要读它的话，路径是 `history/ir.md`（`src/by1debt.py` 就是这么用的）。

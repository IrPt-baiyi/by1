  • llama.cpp

    How to use ggml-org/Qwen3-ASR-0.6B-GGUF with llama.cpp:

    Install (macOS, Linux)
    curl -LsSf https://llama.app/install.sh | sh
# Start a local OpenAI-compatible server with a web UI:
llama serve -hf ggml-org/Qwen3-ASR-0.6B-GGUF:Q8_0
# Run inference directly in the terminal:
llama cli -hf ggml-org/Qwen3-ASR-0.6B-GGUF:Q8_0
    Install from WinGet (Windows)
    winget install llama.cpp
# Start a local OpenAI-compatible server with a web UI:
llama serve -hf ggml-org/Qwen3-ASR-0.6B-GGUF:Q8_0
# Run inference directly in the terminal:
llama cli -hf ggml-org/Qwen3-ASR-0.6B-GGUF:Q8_0
    Use pre-built binary
    # Download pre-built binary from:
# https://github.com/ggerganov/llama.cpp/releases
# Start a local OpenAI-compatible server with a web UI:
./llama-server -hf ggml-org/Qwen3-ASR-0.6B-GGUF:Q8_0
# Run inference directly in the terminal:
./llama-cli -hf ggml-org/Qwen3-ASR-0.6B-GGUF:Q8_0
    Build from source code
    git clone https://github.com/ggerganov/llama.cpp.git
cd llama.cpp
cmake -B build
cmake --build build -j --target llama-server llama-cli
# Start a local OpenAI-compatible server with a web UI:
./build/bin/llama-server -hf ggml-org/Qwen3-ASR-0.6B-GGUF:Q8_0
# Run inference directly in the terminal:
./build/bin/llama-cli -hf ggml-org/Qwen3-ASR-0.6B-GGUF:Q8_0
    Use Docker
    docker model run hf.co/ggml-org/Qwen3-ASR-0.6B-GGUF:Q8_0
